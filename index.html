02 // CONCEITO CHAVE

O que é HATEOAS Nível 3?

🌐
Nível 3 de Richardson
Hypermedia As The Engine Of Application State. É o nível máximo de maturidade REST, onde a própria API guia o cliente fornecendo hiperlinks navegáveis (_links).
🔗
Navegabilidade Autodocumentada
Em vez de o cliente hardcodar URLs, o JSON retornado informa exatamente onde acessar (self), consultar todos (todos-produtos), atualizar (atualizar) e excluir (deletar).
⚙️
Padrão Assembler Limpo
Usamos MercadoModelAssembler com RepresentationModelAssemblerSupport e reflexão Java (methodOn) para zero acoplamento de Strings.

04 // CAMADA 1 — REQUISIÇÃO HTTP
1

O Cliente Envia o JSON (HTTP POST /mercado)

O cliente faz uma chamada para cadastrar um novo produto no servidor Tomcat na porta 8082.

// HTTP POST http://57.156.33.102:8082/mercado // Header: Content-Type: application/json { "nome": "Sabão em Pó Omo 1kg", "tipo": "Limpeza", "setor": "Higiene e Limpeza", "tamanho": "1kg", "preco": 14.90 }
05 // CAMADA 2 — REST CONTROLLER
2

MercadoController & Validação (@Valid)

Recebe o JSON, dispara as validações de Bean Validation e barra dados inválidos antes do Service.

@RestController @RequestMapping("/mercado") @RequiredArgsConstructor public class MercadoController { private final MercadoService service; @PostMapping public ResponseEntity<MercadoResponseDto> create(@Valid @RequestBody MercadoRequestDto dto) { MercadoResponseDto response = service.create(dto); // Dispara para a camada de Serviço se @Valid for aprovado } }
06 // CAMADA 3 — SERVICE & REGRA DE NEGÓCIO
3

MercadoService & Transação (@Transactional)

Aplica regras de negócio, gerencia o ciclo da transação (tudo ou nada) e converte DTO para Entidade JPA.

@Service @RequiredArgsConstructor public class MercadoService { private final MercadoRepository repository; private final MercadoModelAssembler assembler; @Transactional public MercadoResponseDto create(MercadoRequestDto dto) { Mercado entity = Mercado.builder() .nome(dto.getNome()).tipo(dto.getTipo()) .setor(dto.getSetor()).tamanho(dto.getTamanho()).preco(dto.getPreco()) .build(); Mercado savedEntity = repository.save(entity); // Salva no banco Oracle return assembler.toModel(savedEntity); // Converte para DTO com HATEOAS } }
07 // CAMADA 4 — PERSISTÊNCIA & ORACLE DB
4

MercadoRepository & Oracle (TDS_TB_MERCADO)

Executa o INSERT na tabela Oracle atribuindo a Primary Key através da Sequence SQ_TDS_MERCADO.

-- SQL NATIVO EXECUTADO PELO SPRING DATA JPA NO ORACLE: INSERT INTO TDS_TB_MERCADO (ID, NOME, TIPO, SETOR, TAMANHO, PRECO) VALUES (SQ_TDS_MERCADO.NEXTVAL, 'Sabão em Pó Omo 1kg', 'Limpeza', 'Higiene e Limpeza', '1kg', 14.90);
08 // CAMADA 5 — MONTAGEM HATEOAS NÍVEL 3
5

MercadoModelAssembler & Hipermídia (_links)

Converte a entidade salva em MercadoResponseDto injetando a coleção de links navegáveis (_links).

@Override public MercadoResponseDto toModel(Mercado entity) { MercadoResponseDto dto = MercadoResponseDto.fromEntity(entity); dto.add(linkTo(methodOn(MercadoController.class).findById(entity.getId())).withSelfRel()); dto.add(linkTo(methodOn(MercadoController.class).findAll(null)).withRel("todos-produtos")); dto.add(linkTo(methodOn(MercadoController.class).update(entity.getId(), null)).withRel("atualizar")); dto.add(linkTo(methodOn(MercadoController.class).delete(entity.getId())).withRel("deletar")); return dto; }
09 // RETORNO FINAL — HTTP 201 CREATED
6

Resposta HTTP 201 Created + Header Location

O Controller devolve o código HTTP 201 Created com o cabeçalho Location apontando para a URL do novo recurso.

// HTTP/1.1 201 Created // Header Location: http://57.156.33.102:8082/mercado/15 { "id": 15, "nome": "Sabão em Pó Omo 1kg", "tipo": "Limpeza", "setor": "Higiene e Limpeza", "tamanho": "1kg", "preco": 14.90, "_links": { "self": { "href": "http://57.156.33.102:8082/mercado/15" }, "todos-produtos": { "href": "http://57.156.33.102:8082/mercado" }, "atualizar": { "href": "http://57.156.33.102:8082/mercado/15" }, "deletar": { "href": "http://57.156.33.102:8082/mercado/15" } } }
