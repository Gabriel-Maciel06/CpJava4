01 // ESCOPO DO PROJETO

Visão Geral & Requisitos Mercado Express

🛒
Domínio de Negócio
API completa de gestão de estoque para redes de mercado express de conveniência (produtos de limpeza, hortifruti, vestuário, brinquedos e alimentos).
⚡
Porta Obrigatória & Servidor
Servidor web Tomcat configurado na porta 8082 (server.port=8082) atendendo todas as chamadas HTTP.
🎯
Operações CRUD Completas
Endpoints em /mercado contemplando todas as operações: Create (POST), Read (GET), Update (PUT/PATCH) e Delete (DELETE).

03 // MATURIDADE REST

HATEOAS Nível 3 com MercadoModelAssembler

🏛️
Arquitetura Limpa (Clean Code)
A lógica de geração dos links hipermídia foi 100% desacoplada da camada de serviço e isolada na classe dedicada MercadoModelAssembler.
🔗
Hiperlinks Dinâmicos (_links)
Cada produto retornado contém os links RESTful: self, todos-produtos, atualizar, atualizar-parcial e deletar.
04 // PERSISTÊNCIA DE DADOS

Tabela Oracle TDS_TB_MERCADO

CREATE TABLE TDS_TB_MERCADO ( ID NUMBER(19) DEFAULT SQ_TDS_MERCADO.NEXTVAL PRIMARY KEY, NOME VARCHAR2(100) NOT NULL, TIPO VARCHAR2(50) NOT NULL, -- Ex: Limpeza, Alimentos, Vestuário, Brinquedos SETOR VARCHAR2(50) NOT NULL, -- Ex: Higiene e Limpeza, Hortifruti, Bazar TAMANHO VARCHAR2(30) NOT NULL,-- Ex: 500ml, 1kg, Grande, Único PRECO NUMBER(10, 2) NOT NULL, CONSTRAINT CK_PRECO_POSITIVO CHECK (PRECO > 0) );
05 // ENDPOINTS HTTP

Mapeamento de Rotas CRUD (/mercado)

Verbo Endpoint Status Code Descrição do Recurso
GET /mercado 200 OK Lista todos os produtos com links HATEOAS (filtro opcional ?tipo=...).
GET /mercado/{id} 200 OK Consulta produto por ID no banco de dados.
POST /mercado 201 Created Cadastra novo produto e retorna Header Location.
PUT /mercado/{id} 200 OK Atualização completa de todos os atributos.
PATCH /mercado/{id} 200 OK Atualização parcial pontual de campos como preço.
DELETE /mercado/{id} 204 No Content Remove produto por ID no banco Oracle.
